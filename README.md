# ⚽🎮 Football Discrete Event Simulation (DES) Project

## 🌟 Overview
Welcome to the **Football Discrete Event Simulation (DES) Project**! This project is your gateway to understanding the beautiful game through the lens of simulation. By harnessing the power of discrete event simulation, we aim to model and experiment with football phenomena, providing insights that help make informed decisions. 🧠💡

## 🚀 Features
- **🎲 Discrete Event Simulation Engine**: Dive into the heart of the simulation with the `FootballDES` class, where football matches come to life through scheduled events like shots and fouls.
- **🏃‍♂️ Team Dynamics**: Each team is a unique entity with attributes like attack rate, foul rate, attack strength, defense strength, and stamina decay. Feel the thrill of the game as these parameters influence the match!
- **⏱️ Event Scheduling**: Events are meticulously scheduled based on team dynamics and the current game state, ensuring a realistic and engaging simulation experience.
- **💪 Stamina Management**: Experience the ebb and flow of stamina as it impacts team performance over time. Will your team endure the full 90 minutes?
- **📊 Statistical Analysis**: Uncover the secrets of the game with our comprehensive analysis tools, including basic statistics, bootstrap analysis, and sensitivity analysis.
- **🧠 AI-Powered Contextual Insights**: Leverage AI and the Firework API to generate LaTeX reports with rich statistical and football contexts. Perfect for those who want to dive deeper without being a football expert!

## 🎉 How It Works
1. **Kickoff**: The simulation begins with a random kickoff, setting the stage for an exciting match.
2. **Event Processing**: Events unfold in real-time, updating the game state and keeping you on the edge of your seat.
3. **Stamina & Possession**: Watch as stamina levels fluctuate and possession changes hands, adding layers of strategy to the game.
4. **Full-Time Analysis**: At the end of the match, revel in the detailed game state and insights provided by our advanced analysis tools: uses basic stats, bootstrapping and sensitivity analysis + AI interpretation for each result (since I don't know anything about football 😅).
